## Quick Start

Run the following command in the Julia REPL or a notebook:

```julia
import Pkg; Pkg.add(url="https://github.com/ohno/MyPkg81.jl.git")
```

After installation, load the package and verify it works:

```julia
julia> import MyPkg81; MyPkg81.hello()
"Hello, World!"
```
